# 5. 가장 긴 팰린드롬 부분 문자열

## 한국어 문제 설명

문자열 `s`가 주어질 때, `s`에 포함된 부분 문자열 중 가장 긴 팰린드롬을 반환한다. 팰린드롬은 앞에서 읽은 결과와 뒤에서 읽은 결과가 같은 문자열이며, 부분 문자열은 원래 문자열에서 연속한 문자들로 이루어진다.

## 입력 형식

LeetCode 함수형 문제이다. `Solution.longestPalindrome` 함수에 숫자와 영문자로만 이루어진 문자열 `s`가 전달된다.

이 저장소에서 `make run`으로 실행할 때는 첫째 줄에 따옴표 없이 문자열 `s`를 입력한다.

## 출력 형식

`s`의 가장 긴 팰린드롬 부분 문자열 하나를 반환한다.

로컬 실행 시에는 반환할 문자열을 한 줄에 출력한다.

## 제약 조건

- `1 <= s.length <= 1000`
- `s`는 숫자와 영문자로만 이루어진다.

## 예제 입력과 출력

### 예제 1

입력:

```text
babad
```

출력:

```text
bab
```

### 예제 2

입력:

```text
cbbd
```

출력:

```text
bb
```

## 예제에 대한 한국어 설명

예제 1에서 `"bab"`은 앞뒤 어느 방향으로 읽어도 같다. 같은 최대 길이를 갖는 `"aba"`도 올바른 답이다.

예제 2에서 길이 2인 `"bb"`가 가장 긴 팰린드롬 부분 문자열이다.

## 가정 및 주의 사항

- 정답이 여러 개이면 그중 아무 것이나 반환할 수 있다. 이 풀이들은 결과를 일관되게 만들기 위해 가장 왼쪽에서 먼저 발견한 답을 유지한다.
- 원래 제약 조건상 빈 문자열은 입력되지 않는다. 구현은 방어적으로 빈 문자열도 받아 빈 문자열을 반환한다.
